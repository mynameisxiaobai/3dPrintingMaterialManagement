数据管理 · 备份 / 导入 / 清理
数据只存在这台电脑的浏览器本地。换浏览器、清缓存、换电脑都会丢——所以「导出 JSON 备份」是唯一能完整迁移的方式（含耗材、标签、色卡收藏）。CSV 适合丢进 Excel 批量改完再导回来。所有删除都会先进回收站，误删可一键还原。
